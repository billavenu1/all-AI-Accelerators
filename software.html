The shared software layer

Hardware specs only matter if your model's kernels compile and run well. The gap between software stacks is wider than the gap in silicon.

The moat versus open standards

CUDA has nearly two decades of libraries, tooling and developer habit behind it. Everyone else is trying to make the hardware underneath irrelevant, either by cloning the CUDA experience (AMD's HIP) or by pushing the abstraction up to the framework.

The portability layer

FrameworkPyTorch 2.x / torch.compile: the common front end; every vendor here offers a PyTorch path.
ServingvLLM, SGLang: open inference servers that vendors now target directly.
KernelsTriton: write custom kernels once, compile for several back ends.
CompilerMLIR: the infrastructure under most vendor compilers.
