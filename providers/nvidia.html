Host CPU

Vera CPU

×36 per rack · one per two GPUs

Why it's special: Nvidia designed its own Arm cores ("Olympus") instead of licensing them, and gave the CPU 2.4× the memory bandwidth of Grace. Its "spatial multithreading" splits each core's resources physically rather than taking turns, so two threads don't slow each other down. Agents spend a lot of time on CPU work like tool calls and code execution, so this matters more than it used to.

Key numbers (per CPU)

88 / 176cores / threads
1.5 TBLPDDR5X (3× Grace)
1.2 TB/smemory bandwidth (2.4× Grace)
1.8 TB/sNVLink-C2C to its GPUs (2× Grace)

What it does here

  • Runs the operating system, schedules work and feeds data to the two GPUs it is paired with.
  • Shares memory coherently with the GPUs, so they can spill data into its 1.5 TB.
  • Supports confidential computing across CPU and GPU (Grace did not).
  • Armv9.2, 2 MB L2 per core, 164 MB L3, PCIe Gen6 and CXL 3.1.

Its new job is AI-specific: storing and sharing the KV cache (the model's working memory of a conversation) so long agent sessions don't have to recompute it.

Spectrum-6 Ethernet switch

Outside the rack · with co-packaged optics

Signals travel millimetres instead of centimetres before becoming light, which Nvidia says cuts optical loss from about 22 dB to 4 dB and gives about 5× better power efficiency and 10× better reliability.

Concept

Rack power & liquid cooling

A modern AI rack draws as much power as a hundred homes. Almost all of it turns into heat, far more than fans can blow away.

Direct liquid cooling pumps water through metal plates pressed onto each chip. Power shelves convert grid power to the voltages chips need.

Analogy: a car engine. Air cooling works for a lawnmower; a racing engine needs a radiator.
Concept

What is a compute tray?

A tray is a flat drawer that slides into the rack. It holds a few accelerators, their CPUs and network chips on one board.

Racks are built from identical trays so that a broken one can be swapped like a battery, and many trays can be wired together to act as one computer.

Analogy: books on a shelf. The rack is the shelf, each tray is a book, and you can pull one out without moving the rest.
Concept

What is a scale-up switch?

Big models don't fit on one chip, so they're split across many. Those chips must swap partial results constantly, often several times per token.

A scale-up network links chips inside one rack with very high bandwidth and very low delay, so they behave like one big chip. Examples: Nvidia NVLink, AMD/industry UALink, Google ICI.

Analogy: people working in one open-plan room who can just talk, versus emailing another office (scale-out).
Concept

What is a GPU?

A GPU runs thousands of simple calculations in parallel. AI is mostly multiplying huge grids of numbers (matrices), which is exactly that kind of work.

Next to it sits HBM (high-bandwidth memory): stacks of memory chips that hold the model. How fast the GPU can read HBM often limits speed more than the maths does.

Analogy: a CPU is a few expert chefs; a GPU is a thousand line cooks each chopping one vegetable at the same time.
Concept

What is a host CPU?

Accelerators can't run an operating system. A host CPU boots the machine, loads data, launches work onto the accelerators and handles everything that isn't matrix maths.

When a CPU and GPUs share one package with a fast coherent link, Nvidia calls it a superchip.

Analogy: the head chef who reads the orders and hands tasks to the line cooks.
Concept

What is a (Super)NIC?

A network interface card connects a computer to the network. A SuperNIC is a NIC built for AI: huge bandwidth per GPU, hardware congestion control, and the ability to move data straight into GPU memory (RDMA) without bothering the CPU.

Analogy: a dedicated loading dock for each warehouse aisle, instead of one front door for the whole building.
Concept

What is a DPU?

A data processing unit is a network card with its own CPU cores and memory. It takes over the "plumbing" of a data centre: networking, storage access, encryption, firewalls and keeping customers isolated from each other.

That frees the main CPUs and GPUs to do only AI work, and gives the cloud operator a secure control point the customer can't tamper with.

Analogy: a building's security desk and mailroom. Residents (the GPUs) never deal with deliveries or visitors themselves.
Concept

What is a scale-out switch?

Scale-out networks connect racks to each other so thousands of racks can train one model. They use Ethernet or InfiniBand, usually over fibre optics.

Co-packaged optics puts the light-making parts inside the switch chip's package, cutting power and failures compared with plug-in optical modules.

Analogy: the motorway between cities, while scale-up is the streets inside one city.
Concept

What is an LPU?

Groq's Language Processing Unit keeps the model in on-chip SRAM instead of external HBM, and its compiler plans every step in advance. There are no caches or surprises, so each token comes out at a fast, predictable speed.

The trade-off: SRAM is small, so a big model is spread over hundreds of chips.

Analogy: a train timetable, where everything leaves exactly on schedule, versus taxis that react to traffic.

On-chip memory

L2 cache

Shared by every SM on its die

Why it matters: every byte coming from HBM passes through L2. When weights or KV-cache blocks are reused, keeping them in L2 avoids another slow trip to HBM, so a bigger, smarter cache directly lifts real-world throughput.

What it does

  • Buffers data between the SMs and the HBM controllers.
  • Keeps the two dies' views of memory consistent, so software sees one GPU.
  • Nvidia has not published Rubin's L2 size in the materials we checked.

Control

Scheduler & MIG

One per die (Nvidia calls it the GigaThread engine)

Why it matters: a GPU is only fast if all 224 SMs stay busy. The scheduler hands out blocks of work as SMs free up. Multi-Instance GPU (MIG) can also slice one GPU into isolated pieces, so several smaller models or tenants share it safely.

What it does

  • Distributes thread blocks from each kernel across the SMs.
  • MIG has split Nvidia data-centre GPUs into up to seven isolated instances since the A100.
  • The block layout here follows Nvidia's Blackwell diagrams; Rubin's exact floorplan isn't public.

Memory

HBM4 memory

288 GB in stacks around the dies

Why it's special: Rubin is among the first GPUs on HBM4, which doubles each stack's interface to 2,048 bits (HBM3E has 1,024). Wider pipes mean far more bandwidth, and bandwidth, not maths, is what limits how fast a model generates tokens.

Key numbers

288 GBcapacity, same as Blackwell Ultra
22 TB/sbandwidth at launch
19.2 TB/sreported revised figurePRESS
2.4–2.8×Blackwell's 8 TB/s

What it does

  • Holds the model weights and the KV cache of every conversation in flight.
  • Each stack is DRAM dies piled vertically and wired through the silicon, sitting millimetres from the GPU.

Die-to-die

Die-to-die link

Joins the two compute dies

Why it's special: a single chip can't be bigger than the lithography machine's field (the "reticle limit"). Rubin uses two maximum-size dies and stitches them together so tightly that software sees one GPU, not two.

What it does

  • On Blackwell, Nvidia calls this NV-HBI and rates it at 10 TB/s. Rubin's figure isn't in the sources we checked.

Security

Confidential computing

Part of a rack-scale trusted execution environment

Why it's special: Nvidia's third-generation trusted execution environment now spans the whole rack (CPU, GPU and the NVLink between them). A model owner's weights and users' prompts stay encrypted even from the cloud operator running the hardware.

Reliability

RAS engine

Second generation

Why it's special: in a cluster of 100,000 GPUs, something fails every day. Rubin's RAS engine can repair faulty on-chip SRAM in the field and run self-tests without taking the GPU offline, so a single fault doesn't stall a training run.

What it does

  • Monitors the chip's health and predicts failures before they happen.
  • Zero-downtime self-test and in-field SRAM repair (Nvidia claims).

Concept

What are SMs and Tensor Cores?

A streaming multiprocessor (SM) is one of the GPU's many small processors. Each runs thousands of threads in lock-step groups.

Tensor Cores are special units inside each SM that multiply small blocks of a matrix in a single step. A GPC is just a cluster of SMs.

Analogy: the GPU is a factory, a GPC is a hall, an SM is a workstation, and a Tensor Core is the power tool that does one job very fast.
Concept

What is L2 cache?

A cache is a small, very fast memory on the chip that keeps recently used data close to the processors. L2 is the larger, shared level that every SM can reach.

Analogy: HBM is the warehouse; L2 is the shelf right next to the workbench.
Concept

What does the GPU scheduler do?

A program sent to a GPU (a kernel) is split into many blocks of work. The scheduler hands them to whichever SM is free, millions of times a second.

MIG (Multi-Instance GPU) carves one GPU into several smaller, fully isolated GPUs.

Analogy: an air-traffic controller, plus the ability to split one big runway into several private ones.
Concept

What is HBM?

High-bandwidth memory stacks DRAM chips on top of each other and places them right beside the processor on the same package, connected by thousands of tiny wires.

It is much faster than normal memory, but expensive and limited in size, so it is often the real bottleneck for AI.

Analogy: a multi-storey car park next to the stadium, with a hundred exits instead of one.
Concept

What is a die-to-die link?

Chips are printed in patches no bigger than about 26 × 33 mm, the reticle limit. To go bigger, designers build several dies (chiplets) and join them with a very short, very wide link inside the package.

Analogy: two rooms knocked through into one open space. They're still two rooms, but you walk between them freely.
Concept

What is a coherent CPU–GPU link?

Coherent means the CPU and GPU always agree on what is in memory, so either one can read the other's memory directly, with no copying.

Nvidia's chip-to-chip version is called NVLink-C2C, and it is far faster than PCIe.

Analogy: two colleagues editing one shared document instead of emailing copies back and forth.
Concept

What is PCIe?

PCI Express is the standard connection inside almost every computer, linking processors to graphics cards, SSDs and network cards. Each generation roughly doubles its speed.

Analogy: the public road network. Not the fastest route, but it reaches everything.
Concept

What is confidential computing?

Normally data is encrypted on disk and on the network but readable while it is being processed. Confidential computing keeps it encrypted inside a hardware-protected trusted execution environment, even from the machine's owner.

Analogy: a locked glovebox in a lab. You can work on the sample, but nobody else in the room can touch it.
Concept

What does RAS mean?

Reliability, availability and serviceability: the features that detect, survive and fix hardware faults. At data-centre scale, rare faults become everyday events.

Analogy: a car's warning lights plus a mechanic who can fix things while you keep driving.
