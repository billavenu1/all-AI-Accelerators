Qualcomm: Dragonfly AI250 (HBC)

An inference-only rack that puts compute logic underneath the memory, so less data has to travel. The AI250 is not on sale yet: it samples in the first half of 2027. The AI200, which uses ordinary LPDDR memory, is the rack Qualcomm is targeting for customers in 2026.

Concept

Liquid cooling

A rack that draws 140 kW turns nearly all of it into heat. Direct liquid cooling pumps coolant through plates on the chips, which removes heat far better than air.

Analogy: a car engine. A lawnmower can be air-cooled; a racing engine needs a radiator.
Concept

Accelerator card in a rack

An accelerator card is a plug-in board carrying the AI chip and its memory. A rack holds dozens of them and is sold as one system.

Analogy: books on a shelf. The rack is the shelf and each card is a book you can swap out.
Concept

Inference-only accelerator

Training teaches a model. Inference uses the finished model to answer requests. Inference mostly re-reads the model's weights from memory, so memory speed and size matter more than raw maths.

An inference-only chip skips the extras that training needs, and spends its effort on memory instead.

Analogy: a library built for readers, not for authors. It needs many shelves close to the desks, not a printing press.
Concept

Scale-up vs scale-out

Scale-up links the cards inside one rack with very fast, low-delay connections, so a big model can be split across them. PCIe is the standard connection inside a computer; it is not built for AI racks, which is why people ask how well it works here.

Scale-out connects whole racks to each other, here with Ethernet.

Analogy: scale-up is talking across an open-plan room. Scale-out is a letter to another office.
Concept

What is a host CPU?

Accelerators can't run an operating system. A host CPU boots the machine, loads data, sends work to the accelerators and handles everything that isn't matrix maths.

Analogy: the head chef who reads the orders and hands tasks to the line cooks.
Concept

Prefill, decode and disaggregated serving

Answering a prompt has two steps. Prefill reads the whole prompt at once and needs lots of maths. Decode writes the answer one token at a time and spends most of its time fetching weights from memory.

Disaggregated serving runs each step on the hardware that suits it.

Analogy: one cook preps all the ingredients (prefill) while another plates dishes one by one (decode).
Concept

What is a scale-out network?

Scale-out networks join racks so many of them can serve one huge workload. Ethernet is the ordinary data-centre network, and most vendors now offer AI-tuned versions.

Analogy: the motorway between cities, while scale-up is the streets inside one city.

Why it's special: HBM puts memory stacks beside the processor on an interposer, which is costly. HBC bonds ordinary low-power LPDDR layers on top of logic instead. Near-memory compute

Base die (the HBC idea)

Active logic under the DRAM · Qualcomm: near-memory compute, not compute-in-memory

Why it's special: the heaviest memory work, such as the bandwidth-hungry steps of decode, runs right under the DRAM. Only results leave the stack, so far less data has to cross to the main chip. That is where the "effective bandwidth" and energy gains come from.

Concept

Memory wall and near-memory compute

Chips can do maths faster than memory can feed them. This gap is the memory wall, and for AI inference it often sets the speed limit.

Near-memory compute puts some logic right beside the memory, so the data is processed on the spot and only the answer travels.

Analogy: instead of carrying every book to a reader's desk, a clerk in the stacks looks things up and brings only the page you need.
Concept

LPDDR vs HBM, and 3D stacking

HBM is very fast memory built from stacked chips that sit beside the processor, but it is expensive and capacity is limited. LPDDR is the lower-power memory used in phones: slower per chip, cheaper and plentiful.

HBC bonds LPDDR layers directly onto logic, joined by vertical wires called TSVs. Many wires in parallel give a wide data path without an interposer.

Analogy: HBM is a car park beside the stadium. HBC is a stadium built on top of the car park.
Concept

Accelerator SoC and NPU

An SoC (system on chip) packs many functions onto one die. An NPU (neural processing unit) is a block built for AI maths. Qualcomm's Hexagon NPU powers the AI in its phone chips, and the data-centre line builds on that technology.

Analogy: a specialist workshop built only for one trade, instead of a general-purpose garage.
Concept

Confidential computing

Data is normally encrypted when stored and when sent, but not while in use. Confidential computing uses hardware to keep it protected even while the chip works on it, so other tenants and the host operator can't read it.

Analogy: a sealed room where you work on a document: staff can hand you materials but can't look inside.

"Effective bandwidth": read with care

Raw bandwidth is how many bytes per second the wires between memory and processor can carry. Nvidia's Rubin GPU has 288 GB of HBM4 at about 22 TB/s at launch (about 19.2 TB/s in later reports PRESS). AMD's MI455X has 432 GB at 23.3 TB/s.

Effective bandwidth is a different measure. Because the base die does work inside the stack, the main chip doesn't have to read all that data. Effective bandwidth is roughly what a conventional chip would have needed to do the same job. Press analysis describes it as bandwidth available to computation inside the stack PRESS. It is not a speed of wires, so it can't be set beside HBM figures, and it only counts for work the base die can do.

  • The 18× baseline is LPDDR5X designs (the AI200), not HBM. The efficiency claim against HBM4 uses a different baseline PRESS.
  • It comes from a two-layer test stack with random data, scaled to target conditions, not a real model PRESS.
  • The AI200's own figure, 414 TB/s across its 56 chips (about 7.4 TB/s per card, derived), was questioned by The Register: it would need a data bus of about 6,720 bits at 8,800 MT/s PRESS. Qualcomm called it the physical bandwidth of the LPDDR interface and gave no detail.
  • Real speed is tokens per second and per dollar on a real model. Qualcomm has published neither for the AI250. Production yields and power are unconfirmed.

Where it sits in the family

The Cloud AI 100 Ultra card (2023) has 128 GB of LPDDR4x at 548 GB/s and a 150 W budget PRESS. The AI250 card has 6× the capacity (derived: 768 ÷ 128). The bandwidth jump can't be calculated fairly, because one figure is raw and the other effective.

What's next

AI300 brings the second-generation HBC Gen 2. Qualcomm targets up to 54× the AI200's effective bandwidth, with samples in 2028 (a roadmap goal). Gen 2 is reported to add the ESUN and UALink fabrics PRESS. The C1000 CPU (250+ Oryon cores, PCIe Gen7, CXL) samples in 2027; Meta is its first named customer, with production in H2 2028.
