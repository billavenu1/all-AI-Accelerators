Training versus inference

Training

Wants raw compute and very large clusters. Measured in FP8/FP4 petaflops and how many chips can act as one.

Inference

Especially for agents with long contexts, wants memory bandwidth and low cost per token. Several vendors now ship separate parts for each job.

Glossary

TermMeaning
PFLOPS at FP4 / FP8Peak compute in petaflops at 4-bit or 8-bit floating point. Lower precision gives bigger numbers, so only compare like with like.
HBM3e / HBM4Stacked memory beside the chip: large but bandwidth limited.
SRAMMemory on the chip itself: tiny but extremely fast.
Memory bandwidthHow fast the chip reads its memory. For inference this usually matters more than PFLOPS.
Scale-upLinks chips inside a rack into one system (NVLink, UALink, ICI, NeuronLink).
Scale-outLinks racks into a cluster (Ethernet, InfiniBand, EFA).
DPUData processing unit: offloads networking, storage and security from the host CPU.
